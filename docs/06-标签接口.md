# 06 - 标签接口

## 接口列表

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| GET | `/api/tags/list` | 不需要 | 标签列表 |
| GET | `/api/tags/:identifier` | 不需要 | 标签详情及图片 |
| POST | `/api/tags/create` | 管理员 | 创建标签 |
| PUT | `/api/tags/:id` | 管理员 | 更新标签 |
| DELETE | `/api/tags/:id` | 管理员 | 删除标签 |

---

## 标签对象结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 标签ID |
| `name` | string | 标签名称 |
| `slug` | string | 标签标识 |
| `image_count` | integer | 关联的图片数量（仅列表接口返回此字段） |

---

## GET /api/tags/list - 标签列表

**认证要求**：不需要

### 请求参数

无

### 返回值

**成功 200**：按关联图片数量降序排列的标签列表。

```json
{
  "tags": [
    { "id": 1, "name": "风景", "slug": "fengjing", "image_count": 200 },
    { "id": 2, "name": "城市", "slug": "chengshi", "image_count": 150 },
    { "id": 3, "name": "人像", "slug": "renxiang", "image_count": 80 }
  ]
}
```

### 业务处理流程

```
1. SELECT t.id, t.name, t.slug, COUNT(it.image_id) as image_count
   FROM tags t LEFT JOIN image_tags it ON t.id = it.tag_id
   GROUP BY t.id ORDER BY image_count DESC
2. 返回 200
```

## GET /api/tags/:identifier - 标签详情及图片

**认证要求**：不需要

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `identifier` | Path | string | 是 | — | 标签 slug 或名称 |
| `page` | Query | integer | 否 | `1` | 页码 |
| `limit` | Query | integer | 否 | `20` | 每页数量（最大 50） |

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `tag` | object | 标签信息 |
| `images` | array | 该标签下的图片列表 |
| `pagination` | object | 分页信息 |

```json
{
  "tag": { "id": 1, "name": "风景", "slug": "fengjing" },
  "images": [ { "id": 42, "title": "山间日出", "tags": [...], ... } ],
  "pagination": { "page": 1, "limit": 20, "total": 200, "total_pages": 10 }
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"无效的标签"` | identifier 为空 |
| 404 | `"标签不存在"` | 无匹配的标签 |

### 业务处理流程

```
1. 校验 identifier 非空
2. 先按 slug 查询，未找到则按 name 查询
   ↓ 均未找到 → 404
3. 分页查询 image_tags 关联的图片
4. 格式化图片（标签、EXIF、签名URL）
5. 返回 200
```

## POST /api/tags/create - 创建标签

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `name` | Body | string | 是 | 标签名称 |
| `slug` | Body | string | 否 | 标签标识（不提供则根据 name 自动生成） |

### 请求示例

```json
{
  "name": "微距摄影"
}
```

### 返回值

**成功 201：**

```json
{
  "message": "标签已创建",
  "slug": "weiju-sheying"
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"标签名称不能为空"` | name 为空 |
| 400 | `"标签已存在"` | name 重复 |
| 400 | `"标签标识已存在"` | slug 已占用 |
| 401 | `"未登录"` | — |
| 403 | `"需要管理员权限"` | — |

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 提取 name + 校验非空
3. 检查标签名称唯一性
   ↓ 重复 → 400
4. 处理 slug：
   - 如提供：小写 + 非法字符替换 '-'
   - 不提供：根据 name 自动生成
5. 检查 slug 唯一性
   ↓ 重复 → 400
6. INSERT INTO tags (name, slug)
7. 返回 201
```

## PUT /api/tags/:id - 更新标签

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `id` | Path | integer | 是 | — | 标签ID |
| `name` | Body | string | 是 | — | 新标签名称 |
| `slug` | Body | string | 否 | 保持原slug | 新标签标识 |

### 请求示例

```json
{
  "name": "微距世界"
}
```

### 返回值

**成功 200：**

```json
{
  "message": "标签已更新",
  "slug": "weiju-sheying"
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"标签名称不能为空"` | name 为空 |
| 400 | `"标签名称已存在"` | name 被其他标签占用 |
| 400 | `"标签标识已存在"` | slug 被其他标签占用 |
| 404 | `"标签不存在"` | — |

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 查询标签
   ↓ 不存在 → 404
3. 验证 name 非空
4. 检查 name 唯一性（排除自身）
5. 处理 slug（提供则校验，不提供则保持原值）
6. UPDATE tags SET name=?, slug=? WHERE id=?
7. 返回 200
```

---

## DELETE /api/tags/:id - 删除标签

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `id` | Path | integer | 是 | 标签ID |

### 返回值

**成功 200：**

```json
{
  "message": "标签已删除"
}
```

**失败 404：**

```json
{
  "error": "标签不存在"
}
```

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 查询标签
   ↓ 不存在 → 404
3. 删除关联：DELETE FROM image_tags WHERE tag_id = ?
4. 删除标签：DELETE FROM tags WHERE id = ?
5. 返回 200
```
