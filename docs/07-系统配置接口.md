## GET /api/config - 获取系统配置

**认证要求**：不需要（公开接口）

### 请求参数

无

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `maxFileSizeMB` | number | 单文件最大上传大小（MB） |
| `maxFileSizeBytes` | number | 单文件最大上传大小（字节） |
| `maxBatchCount` | integer | 批量上传最大文件数量 |
| `allowedTypes` | string[] | 允许的 MIME 类型列表 |

```json
{
  "maxFileSizeMB": 20,
  "maxFileSizeBytes": 20971520,
  "maxBatchCount": 10,
  "allowedTypes": [
    "image/jpeg",
    "image/png",
    "image/webp",
    "image/gif",
    "image/svg+xml",
    "image/tiff",
    "image/bmp"
  ]
}
```

### 业务处理流程

```
1. 从 config/app.js 读取配置
2. maxFileSizeBytes = maxFileSizeMB × 1024 × 1024
3. 返回 200
```

### 使用场景

- 前端上传组件据此动态限制文件大小和类型
- 批量上传组件据此显示最大可选文件数量
- 无需每次修改代码，修改配置即可生效
