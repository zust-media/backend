## GET /api/admin/stats - 站点统计数据

**认证要求**：管理员（`requireAdmin`）

### 请求参数

无

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `totalUsers` | integer | 用户总数 |
| `totalImages` | integer | 图片总数 |
| `totalCategories` | integer | 分类总数 |
| `totalTags` | integer | 标签总数 |
| `totalSize` | integer | 已用存储空间（字节） |
| `duplicateCount` | integer | 重复图片数量 |
| `recentImages` | array | 最近5张上传的图片 |
| `topUploaders` | array | 上传排行榜（前5名） |

`recentImages` 每项结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 图片ID |
| `title` | string | 标题 |
| `original_name` | string | 原始文件名 |
| `file_size` | integer | 文件大小（字节） |
| `created_at` | string | 上传时间 |
| `username` | string | 上传者用户名 |

`topUploaders` 每项结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `username` | string | 用户名 |
| `role` | string | 角色 |
| `cnt` | integer | 上传数量 |

```json
{
  "totalUsers": 25,
  "totalImages": 1500,
  "totalCategories": 8,
  "totalTags": 45,
  "totalSize": 5368709120,
  "duplicateCount": 12,
  "recentImages": [
    {
      "id": 1500,
      "title": "日落",
      "original_name": "sunset.jpg",
      "file_size": 2048576,
      "created_at": "2026-01-08T12:00:00.000Z",
      "username": "user123"
    }
  ],
  "topUploaders": [
    { "username": "admin", "role": "admin", "cnt": 350 },
    { "username": "user123", "role": "user", "cnt": 200 }
  ]
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 401 | `"未登录"` | Token 未提供或无效 |
| 403 | `"需要管理员权限"` | 用户角色不是 admin |

### 业务处理流程

```
1. requireAdmin：验证登录 + 管理员权限
2. 并行执行以下查询：
   a. COUNT(*) FROM users → totalUsers
   b. COUNT(*) FROM images → totalImages
   c. COUNT(*) FROM categories → totalCategories
   d. COUNT(*) FROM tags → totalTags
   e. SUM(file_size) FROM images → totalSize
   f. COUNT(*) FROM images WHERE is_duplicate=1 → duplicateCount
   g. SELECT ... FROM images JOIN users ORDER BY created_at DESC LIMIT 5 → recentImages
   h. SELECT u.username, u.role, COUNT(i.id) as cnt
      FROM users u LEFT JOIN images i GROUP BY u.id
      ORDER BY cnt DESC LIMIT 5 → topUploaders
3. 合并结果
4. 返回 200
```
