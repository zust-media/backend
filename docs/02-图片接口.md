## POST /api/images/upload - 上传单张图片

**认证要求**：需要（`requireAuth`）  
**Content-Type**：`multipart/form-data`

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `file` | FormData | file | 是 | — | 图片文件 |
| `title` | FormData | string | 否 | — | 图片标题 |
| `description` | FormData | string | 否 | — | 图片描述 |
| `tags` | FormData | string | 否 | — | 标签JSON数组字符串，如 `'["风景","自然"]'` |
| `category_id` | FormData | integer | 否 | — | 分类ID |

### 请求示例

```
POST /api/images/upload
Content-Type: multipart/form-data

file: (binary)
title: 日出风景
tags: ["风景","日出"]
category_id: 2
```

### 返回值

**成功 201：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `message` | string | `"上传成功"` |
| `is_duplicate` | boolean | 是否检测为重复文件 |
| `duplicate_of` | integer/null | 重复于哪个图片ID（非重复时为null） |
| `image` | object | 上传的图片摘要信息 |
| `image.id` | integer | 图片ID |
| `image.uuid` | string | 图片UUID |
| `image.title` | string | 标题 |
| `image.filename` | string | 存储文件名 |

```json
{
  "message": "上传成功",
  "is_duplicate": false,
  "duplicate_of": null,
  "image": {
    "id": 42,
    "uuid": "abc-def-123",
    "title": "日出风景",
    "filename": "20260108120000-a1b2c3.jpg"
  }
}
```

**重复文件上传成功 201：**

```json
{
  "message": "文件已存在",
  "is_duplicate": true,
  "duplicate_of": 15,
  "image": {
    "id": 42,
    "uuid": "abc-def-456",
    "title": "日出风景",
    "filename": "20260108120000-d4e5f6.jpg"
  }
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"文件大小超过限制（最大XMB）"` | 文件过大 |
| 400 | `"不支持的图片格式"` | MIME类型不在允许列表中 |
| 400 | `"内容包含敏感词"` | 标题/描述触发了敏感词过滤 |
| 400 | `"请不要提供过多标签"` | 标签数量过多 |
| 400 | `"上传失败"` | 其他上传处理错误 |
| 401 | `"未登录"` | Token 未提供 |
| 500 | `"文件写入出错"` | 磁盘写入失败 |

### 业务处理流程

```
1. multer 中间件：接收文件上传
   ↓ 文件过大 → 400 文件大小超限
2. requireAuth：验证登录状态
3. 校验文件存在
   ↓ 不存在 → 400 上传失败
4. 校验 MIME 类型
   ↓ 不支持 → 400 不支持的图片格式
5. 计算文件 SHA256 哈希值
6. 检查是否已有相同哈希的文件（重复检测）
7. 使用 sharp 提取 EXIF 信息
8. 解析 tags（JSON数组字符串→数组）
9. 过滤标签数量
   ↓ 超限 → 400 不提供过多标签
10. 生成 UUID
11. 生成存储文件名：`YYYYMMDDHHmmss-{随机8位hex}.{扩展名}`
12. 敏感词过滤（标题、描述）
    ↓ 触发 → 400 包含敏感词
13. 写入 images 表（包括 filename, original_name, original_hash, mime_type, file_size, title, description, category_id, exif, is_duplicate, duplicate_of, user_id, uuid）
14. 关联标签：写入 image_tags 表
15. 返回 201
```

## POST /api/images/batch-upload - 批量上传

**认证要求**：需要（`requireAuth`）  
**Content-Type**：`multipart/form-data`

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `files` | FormData | file[] | 是 | — | 图片文件列表 |
| `category_id` | FormData | integer | 否 | — | 分类ID |

### 返回值

**成功 201：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `message` | string | `"上传完成"` |
| `duplicate_count` | integer | 检测到的重复文件数量 |
| `uploaded` | array | 成功上传的图片列表 |
| `uploaded[].id` | integer | 图片ID |
| `uploaded[].uuid` | string | 图片UUID |
| `uploaded[].original_name` | string | 原始文件名 |
| `uploaded[].filename` | string | 存储文件名 |
| `uploaded[].is_duplicate` | boolean | 是否为重复文件 |
| `uploaded[].duplicate_of` | integer/null | 重复于哪个图片ID |
| `errors` | string[] | 失败的文件错误信息列表 |

```json
{
  "message": "上传完成",
  "duplicate_count": 1,
  "uploaded": [
    {
      "id": 42,
      "uuid": "abc-001",
      "original_name": "sunset.jpg",
      "filename": "20260108120000-a1b2c3.jpg",
      "is_duplicate": false,
      "duplicate_of": null
    },
    {
      "id": 43,
      "uuid": "abc-002",
      "original_name": "mountain.jpg",
      "filename": "20260108120001-d4e5f6.jpg",
      "is_duplicate": true,
      "duplicate_of": 15
    }
  ],
  "errors": [
    "not-an-image.txt - 不支持的图片格式"
  ]
}
```

**失败 400：**

| 错误信息 | 触发条件 |
|----------|----------|
| `"超出批量上传数量限制（最大X）"` | 文件数量超限 |

### 业务处理流程

```
1. multer 中间件：接收多文件上传
2. requireAuth：验证登录状态
3. 检查文件数量
   ↓ 超限 → 400 超出批量上传数量限制
4. 遍历每个文件：
   a. 校验 MIME 类型 → 不通过则记录 errors
   b. 计算 SHA256 哈希 → 重复检测
   c. 提取 EXIF
   d. 生成 UUID、存储文件名
   e. 写入数据库
   f. 如成功，加入 uploaded 列表；如失败，加入 errors 列表
5. 统计 duplicate_count
6. 返回 201
```

## GET /api/images/list - 图片列表

**认证要求**：不需要（公开接口）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `page` | Query | integer | 否 | `1` | 页码 |
| `limit` | Query | integer | 否 | `20` | 每页数量（最大 50） |
| `tag` | Query | string | 否 | — | 按单个标签筛选（已废弃，建议用 `tags`） |
| `tags` | Query | string | 否 | — | 多标签筛选，逗号分隔，如 `"风景,自然"` |
| `tag_match` | Query | string | 否 | `"any"` | 标签匹配模式：`any`=任一匹配 / `all`=全部匹配 |
| `search` | Query | string | 否 | — | 关键词搜索（匹配标题和原始文件名） |
| `my` | Query | string | 否 | — | 设为 `"1"` 仅查看自己的图片 |
| `user_id` | Query | integer | 否 | — | 按上传者用户ID筛选 |
| `category_id` | Query | integer | 否 | — | 按分类ID筛选 |
| `sort` | Query | string | 否 | `"upload_time"` | 排序字段：`relevance` / `upload_time` / `created_time` / `name` / `filesize` |
| `sort_order` | Query | string | 否 | `"desc"` | 排序方向：`asc` / `desc` |

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `images` | array | 图片对象列表 |
| `pagination` | object | 分页信息 |

```json
{
  "images": [
    {
      "id": 1,
      "uuid": "abc-001",
      "user_id": 1,
      "uploader_name": "admin",
      "filename": "20260108-a1b2c3.jpg",
      "original_name": "photo.jpg",
      "mime_type": "image/jpeg",
      "file_size": 2048576,
      "title": "日落",
      "description": "美丽的日落风景",
      "category_id": 2,
      "tags": [{ "id": 1, "name": "风景", "slug": "fengjing" }],
      "exif": { "make": "Canon", "model": "EOS R5" },
      "thumbnail_url": "http://localhost:8080/api/img/20260108-a1b2c3.jpg?w=300&q=80&sig=...",
      "preview_url": "http://localhost:8080/api/img/20260108-a1b2c3.jpg?w=1200&q=80&sig=...",
      "download_url": "http://localhost:8080/api/img/20260108-a1b2c3.jpg?q=80&dl=1&sig=...",
      "created_at": "2026-01-08T12:00:00.000Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100,
    "total_pages": 5
  }
}
```

### 业务处理流程

```
1. 解析查询参数，设置默认值
2. 构建 SQL WHERE 条件：
   - search → title/description LIKE '%keyword%'
   - tags + tag_match → JOIN image_tags，根据匹配模式筛选
   - my=1 → WHERE user_id = 当前登录用户
   - user_id → WHERE user_id = 指定值
   - category_id → WHERE category_id = 指定值
   - 单标签 tag → 兼容旧参数
3. 构建排序：sort + sort_order
4. 执行 COUNT 查询获取总数
5. 执行分页查询（LIMIT + OFFSET）
6. 为每张图片：
   - 关联查询标签（image_tags JOIN tags）
   - 解析 EXIF JSON
   - 生成签名URL（thumbnail/preview/download）
7. 返回 200
```

## PUT /api/images/detail/:id - 更新图片详情

**认证要求**：需要（`requireAuth`）  
**权限**：仅上传者本人或管理员

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `id` | Path | integer | 是 | 图片ID |
| `title` | Body | string | 否 | 图片标题 |
| `description` | Body | string | 否 | 图片描述 |
| `tags` | Body | string[] | 否 | 标签名称列表（覆盖模式） |
| `category_id` | Body | integer/null | 否 | 分类ID |

### 请求示例

```json
{
  "title": "新标题",
  "description": "新描述",
  "tags": ["风景", "日落"],
  "category_id": 3
}
```

### 返回值

**成功 200：**

```json
{
  "message": "更新成功"
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"无效的图片ID"` | id 无效 |
| 400 | `"内容包含敏感词"` | 标题/描述触发敏感词过滤 |
| 401 | `"未登录"` | Token未提供 |
| 403 | `"无权限"` | 非上传者且非管理员 |
| 404 | `"图片不存在"` | 图片未找到 |

### 业务处理流程

```
1. requireAuth：验证登录
2. 校验图片ID
3. 查询图片记录，获取上传者 user_id
   ↓ 不存在 → 404
4. 权限检查：当前用户.id === 图片.user_id 或 当前用户.role === 'admin'
   ↓ 不满足 → 403 无权限
5. 敏感词过滤（标题、描述）
6. 更新 images 表（仅更新提供了的字段）
7. 如果提供了 tags：覆盖模式更新 image_tags（先删后插）
8. 返回 200
```

## POST /api/images/sign-url - 生成签名URL

**认证要求**：不需要

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `filename` | Body | string | 是 | — | 图片文件名 |
| `w` | Body | integer | 否 | — | 宽度（像素） |
| `q` | Body | integer | 否 | 80 | 质量（1-100） |
| `m` | Body | string | 否 | — | 水印模式 |
| `dl` | Body | string | 否 | — | 设为 `"1"` 表示下载模式 |

### 请求示例

```json
{
  "filename": "20260108-a1b2c3.jpg",
  "w": 800,
  "q": 90
}
```

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `filename` | string | 图片文件名 |
| `params` | object | 实际使用的参数 |
| `label` | string | 参数的可读描述 |
| `url` | string | 带签名的完整URL |

```json
{
  "filename": "20260108-a1b2c3.jpg",
  "params": { "w": "800", "q": "90" },
  "label": "宽 800px / 质量 90",
  "url": "http://localhost:8080/api/img/20260108-a1b2c3.jpg?w=800&q=90&sig=..."
}
```

**失败 400：**

```json
{
  "error": "缺少参数"
}
```

**失败 404：**

```json
{
  "error": "图片不存在"
}
```

### 业务处理流程

```
1. 校验 filename 是否提供
   ↓ 未提供 → 400 缺少参数
2. 验证图片在数据库中是否存在
   ↓ 不存在 → 404 图片不存在
3. 处理参数：w→宽度，q→质量，m→水印，dl→下载
4. 调用 generateSignedUrl 生成签名URL
5. 返回 200
```

## GET /api/images/batch-info - 批量编辑预填信息

**认证要求**：需要（`requireAuth`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `ids` | Query | string | 是 | 逗号分隔的图片ID列表，如 `"1,2,3"` |

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `count` | integer | 有效图片数量 |
| `common_category_id` | integer/null | 公共分类ID（仅当所有图片属于同一分类时返回，否则null） |
| `common_tags` | array | 所有图片共有的标签交集 `[{ id, name, slug }]` |
| `all_tags` | array | 所有图片标签的并集（含计数）`[{ id, name, count }]` |
| `categories` | array | 所有可用分类列表（供选择） |

```json
{
  "count": 3,
  "common_category_id": null,
  "common_tags": [{ "id": 1, "name": "风景", "slug": "fengjing" }],
  "all_tags": [
    { "id": 1, "name": "风景", "count": 3 },
    { "id": 2, "name": "日出", "count": 1 }
  ],
  "categories": [
    { "id": 1, "name": "未分类", "slug": "uncategorized", "image_count": 10 }
  ]
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"缺少图片ID"` | ids 未提供 |
| 403 | `"无权限"` | — |

### 业务处理流程

```
1. requireAuth：验证登录
2. 解析 ids 参数（逗号分隔 → 数组）
3. 权限检查（admin 可查任意，普通用户仅限自己的图片）
4. 查询每条图片记录的 category_id
   → 如果全部指向同一个分类 → common_category_id = 该分类ID
   → 否则 → common_category_id = null
5. 查询所有图片的标签：
   → common_tags: 在所有选中的图片中都存在的标签
   → all_tags: 所有选中的图片中出现的标签（含出现次数）
6. 查询所有可用分类
7. 返回 200
```


```
3. 遍历 ids：
   a. 如提供 category_id → 更新图片的 category_id
   b. 如提供 tags（覆盖模式）→ 删除所有原标签，插入新标签
```

## GET /api/img/:filename - 图片文件服务

**认证要求**：不需要登录，但需要**签名验证**（`requireValidSig`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `filename` | Path | string | 是 | — | 图片存储文件名 |
| `w` | Query | integer | 否 | — | 图片宽度（像素），不提供则不缩放 |
| `q` | Query | integer | 否 | 80 | 图片质量（1-100） |
| `m` | Query | string | 否 | — | 水印模式（水印文件名） |
| `dl` | Query | string | 否 | — | 设为 `"1"` 触发浏览器下载 |
| `sig` | Query | string | 是 | — | URL 签名（由 generateSignedUrl 生成） |
| `exp` | Query | integer | 否 | — | 签名过期时间戳 |

### 返回值

**成功 200**：返回图片二进制数据。

响应头：

| 响应头 | 说明 |
|--------|------|
| `Content-Type` | `image/jpeg` 或 `image/png` |
| `Content-Length` | 文件大小（字节） |
| `Cache-Control` | `public, max-age=604800, immutable`（非下载模式） |
| `Content-Disposition` | `attachment; filename="..."` （仅下载模式） |

**失败 404**：

```json
{
  "error": "图片不存在或处理失败"
}
```

**失败 403（签名无效）**：

```json
{
  "error": "签名无效或已过期"
}
```

**失败 500**：

```json
{
  "error": "图片处理失败"
}
```

### 业务处理流程

```
1. requireValidSig 中间件：
   a. 提取 sig、exp 参数
   b. 验证签名：HMAC-SHA256(filename + sorted_params, SECRET_KEY)
   c. 检查过期时间
   ↓ 无效/过期 → 403 签名无效或已过期
2. 提取 filename（basename 防路径穿越）
3. 调用 serveImage(filename, options)：
   a. 读取 uploads/ 目录下文件
      ↓ 不存在 → 404
   b. 若为 SVG → 直接返回
   c. 若指定了 w 且原图更宽 → 等比缩放到 w 宽度
   d. 编码（PNG 保持 PNG，其他转 JPEG，使用 q 质量参数）
   e. 若有水印 → 叠加水印
   f. 返回处理后的 buffer
4. 设置响应头（Content-Type, Cache-Control/Content-Disposition）
5. 返回二进制数据
```
