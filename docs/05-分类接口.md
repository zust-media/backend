# 05 - 分类接口

## 接口列表

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| GET | `/api/categories/list` | 不需要 | 分类列表 |
| GET | `/api/categories/:slug` | 不需要 | 分类详情及图片 |
| POST | `/api/categories/create` | 管理员 | 创建分类 |
| PUT | `/api/categories/:id` | 管理员 | 更新分类 |
| DELETE | `/api/categories/:id` | 管理员 | 删除分类 |

---

## 分类对象结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 分类ID |
| `name` | string | 分类名称 |
| `slug` | string | 分类标识（URL友好字符串） |
| `description` | string | 分类描述 |
| `image_count` | integer | 该分类下的图片数量 |
| `created_at` | string | 创建时间 |

---

## GET /api/categories/list - 分类列表

**认证要求**：不需要

### 请求参数

无

### 返回值

**成功 200：**

```json
{
  "categories": [
    {
      "id": 1,
      "name": "未分类",
      "slug": "uncategorized",
      "description": "默认分类",
      "image_count": 120,
      "created_at": "2025-01-01T00:00:00.000Z"
    },
    {
      "id": 2,
      "name": "风景摄影",
      "slug": "landscape",
      "description": "自然风光类",
      "image_count": 350,
      "created_at": "2025-01-01T00:00:00.000Z"
    }
  ]
}
```

### 业务处理流程

```
1. SELECT c.*, COUNT(i.id) as image_count
   FROM categories c LEFT JOIN images i ON i.category_id = c.id
   GROUP BY c.id ORDER BY c.id ASC
2. 返回 200
```

## GET /api/categories/:slug - 分类详情及图片

**认证要求**：不需要

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `slug` | Path | string | 是 | — | 分类slug |
| `page` | Query | integer | 否 | `1` | 页码 |
| `limit` | Query | integer | 否 | `20` | 每页数量（最大 50） |

### 返回值

**成功 200：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `category` | object | 分类信息 |
| `images` | array | 该分类下的图片列表 |
| `pagination` | object | 分页信息 |

**失败 400：**

```json
{
  "error": "无效的分类"
}
```

**失败 404：**

```json
{
  "error": "分类不存在"
}
```

### 业务处理流程

```
1. 校验 slug 非空
   ↓ 为空 → 400 无效的分类
2. SELECT * FROM categories WHERE slug = ?
   ↓ 不存在 → 404
3. 分页查询该分类的图片（ORDER BY created_at DESC）
4. 格式化图片（标签、EXIF、签名URL）
5. 返回 200
```

## POST /api/categories/create - 创建分类

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `name` | Body | string | 是 | 分类名称 |
| `slug` | Body | string | 是 | 分类标识（URL友好字符串，自动转为小写，非法字符替换为 `-`） |
| `description` | Body | string | 否 | 分类描述 |

### 请求示例

```json
{
  "name": "人像摄影",
  "slug": "portrait",
  "description": "人物肖像类摄影作品"
}
```

### 返回值

**成功 201：**

```json
{
  "message": "分类已创建"
}
```

**失败响应：**

| 状态码 | 错误信息 | 触发条件 |
|--------|----------|----------|
| 400 | `"分类名称不能为空"` | name 为空 |
| 400 | `"分类标识不能为空"` | slug 为空 |
| 400 | `"分类名称或标识已存在"` | name 或 slug 重复 |
| 401 | `"未登录"` | — |
| 403 | `"需要管理员权限"` | — |

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 提取 name、slug、description
3. 处理 slug：小写 + 非法字符替换为 '-' + 去首尾连字符
4. 验证 name 和 slug 非空
5. 检查唯一性：slug 和 name 不可重复
   ↓ 重复 → 400
6. INSERT INTO categories (name, slug, description)
7. 返回 201
```

## PUT /api/categories/:id - 更新分类

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `id` | Path | integer | 是 | — | 分类ID |
| `name` | Body | string | 是 | — | 新分类名称 |
| `slug` | Body | string | 否 | 保持原slug | 新分类标识（可选，不传则不变） |
| `description` | Body | string | 否 | — | 新分类描述 |

### 请求示例

```json
{
  "name": "风光摄影",
  "description": "自然风光摄影作品合集"
}
```

### 返回值

**成功 200：**

```json
{
  "message": "分类已更新"
}
```

**失败 400：**

| 错误信息 | 触发条件 |
|----------|----------|
| `"分类名称不能为空"` | name 为空 |
| `"分类名称已存在"` | name 被其他分类占用 |
| `"分类标识已存在"` | slug 被其他分类占用 |

**失败 404：**

```json
{
  "error": "分类不存在"
}
```

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 查询分类
   ↓ 不存在 → 404
3. 验证 name 非空
4. 检查 name 唯一性（排除自身）
5. 处理 slug（如提供则校验唯一性，不提供则保持原值）
6. UPDATE categories SET name=?, slug=?, description=? WHERE id=?
7. 返回 200
```

---

## DELETE /api/categories/:id - 删除分类

**认证要求**：管理员（`requireAdmin`）

### 请求参数

| 参数名 | 位置 | 类型 | 必需 | 说明 |
|--------|------|------|------|------|
| `id` | Path | integer | 是 | 分类ID |

### 返回值

**成功 200：**

```json
{
  "message": "分类已删除"
}
```

**失败 400：**

```json
{
  "error": "默认分类不可删除"
}
```

> `slug` 为 `"uncategorized"` 的分类为系统默认分类，不可删除。

**失败 404：**

```json
{
  "error": "分类不存在"
}
```

### 业务处理流程

```
1. requireAdmin：验证管理员权限
2. 查询分类
   ↓ 不存在 → 404
3. 检查是否为默认分类（slug === 'uncategorized'）
   ↓ 是 → 400 默认分类不可删除
4. DELETE FROM categories WHERE id = ?
5. 返回 200
```
